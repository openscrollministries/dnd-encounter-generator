# Quick Encounter Generator (D&D 5e)

A free, single-page random encounter generator for Dungeon Masters. Pick party size, level, setting, monster type, and difficulty (or type a request like "4 monsters for 5 third level characters in a swamp") and get balanced monsters with full stat blocks, a difficulty rating (DMG XP thresholds), a suspense hook, a trap, NPCs, and treasure. Works offline: just open `index.html`.

**Live:** https://openscrollministries.github.io/dnd-encounter-generator/
